## Highlights

- Scan currently open Windows app windows.
- Preview real windows inside the InfiniteDesk workspace.
- Arrange windows on a canvas and apply the layout back to Windows.
- Select multiple windows with Ctrl+Drag.
- Move selected window groups together.
- Pan horizontally with Shift+Scroll.
- Save and restore Workspaces.
- Launch local apps from the Dock.
- Use Mirror Control for click, drag, scroll, and focus relay.
- Use Native Overlay as a translucent desktop control layer.

## Notes

- Windows only.
- This is a pre-release build.
- The installer is not code-signed, so Windows SmartScreen or antivirus warnings may appear.
- InfiniteDesk currently does not use analytics, ads, account login, remote telemetry, or auto-update.
- Auto-update artifacts such as `latest.yml` and `.blockmap` are not needed for this GitHub-only release unless auto-update is added later.
